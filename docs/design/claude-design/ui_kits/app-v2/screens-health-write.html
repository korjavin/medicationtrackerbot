Health write-back

From Developer and Miles (2026-11-04): write the app's own BP and weight entries to Health Connect and Apple Health, behind a switch that is off by default. This page draws the switch and its one-line disclosure on the Health import card. One design for web, shared by both shells. Data: the Android QA vault.

Answers to the open questions

Recommended; awaiting Developer.

  • Where: a second switch row in the Health Connect / Apple Health card on Settings home, shown only while import is on. Turning import off also turns writing off, and the switch returns off next time; nothing writes while the row is hidden.
  • Label: “Also write my entries” (Miles' wording); the aria label names the store.
  • Disclosure: one line, always visible: “Copies your new blood pressure and weight entries to Health Connect. Apps you allow there can read them. Turning this off keeps copies already there.” Which entries count (this device only, or also Telegram/voice/AI-app entries) follows Archie's ruling; Socrates checks the final string against the manifest row.
  • From now on only: turning it on does not back-fill old entries (Archie to confirm in the beads).
  • Refused access: switch back off + where to allow it (HW3). No dialog.
  • Unchanged: the import switch, its status line, the rest of Settings home.
