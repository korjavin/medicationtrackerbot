Workouts

The session leaves the modal and becomes a full-screen takeover. It has its own top bar, progress, one exercise at a time, 56px set cells with last session's values ghosted in, tap-to-complete, and a rest timer. The plan editor becomes pushed pages (Plan → Day → Exercise) instead of three stacked sheets. Closing the takeover keeps the session alive, so the stale "Add exercise" modal bug can't happen.

Session takeover

Tap the check to complete a set at the shown values. Tap a cell to adjust it with ± (no keyboard) or type a value. Swipe sideways or tap the progress bar to move between exercises.

Plan editor · pushed pages

Each level is a page with its own Save. The back label always names the parent. Edits on a child save into the parent's draft, and the parent's Save commits everything, so there are never three Cancel/Save headers stacked on top of each other.
