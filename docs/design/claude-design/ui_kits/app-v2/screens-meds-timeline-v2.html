Meds timeline v2

From Developer's test on every platform (2026-10-25): Tomorrow looked like today, history never ended, and the thing to act on didn't stand out. This revises MT1. Proposed kit additions, in this page's style block: .wg-tl-focus (focus card), .wg-tl-planned (planned days) and .wg-tl-more (the show-more row).

Answers to the open questions

  • 1 · Tomorrow vs today. Today's shipped page puts Tomorrow first, above Today, in the same cards, so it reads as today. Now the page has a fixed order: focus card → Today → Coming up → History, and each block is named. Coming up rows are drawn as planned (dashed, dimmed, a "Planned" tag, no buttons), and "Show 3 more days" extends it.
  • 2 · History isn't endless. Yesterday and the day before by default. "Show earlier" adds three days per tap, read locally and instantly. The page remembers nothing, so it opens short every time.
  • 3 · The focus card. It holds the latest pending dose (any day) and the next dose due today, and it's the only accent card on the page. The sun is the Take on its first row. "+N more" jumps to the rest. The empty state names the next dose (TL3).
  • No "missed". Unchanged: a dose stays pending until it's taken or skipped, on any day (TL4).
  • Scope. All of this is shared web code over the dose engine and the Phase 2 projection (med-wi09.12). MT2–MT7 keep their rules inside the new blocks: zones, conflicts, the correct sheet and bulk undo.
