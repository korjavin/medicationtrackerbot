Workout · add exercise

Adding an exercise mid-workout joins the normal flow (epic med-okwf, brief docs/design/briefs/workout-add-exercise.md). One tap from any exercise screen, no Sets/Reps/Weight form, one pending set pre-filled from last time, and Next › on the last exercise asks "What's next?" with suggestions from your own history. Sets can be deleted again. One new layout class: .wg-session-foot__nav.

Answers to the open questions

Developer, 2026-10-29.

  • Where's the button? A plus icon at the left of the footer on every exercise screen, and the last row of the overview list. Prev and Next become two equal labelled buttons (Developer: the bare back chevron was too small). The top bar keeps only Finish.
  • Save in the sheet? No. Tapping a row adds the exercise; a typed name gets an "Add “name”" row.
  • The pre-filled set is a normal pending set with ghost values labelled "last" or "default", or empty.
  • Sheet and Next step share one list: up to 3 suggestions, then search.
  • No reasons on suggestions (Developer). Rows show last time's numbers, or "Library · body part".
  • No Undo toast (Developer).
  • Order: the new exercise goes to the end, as today.
  • Delete a set (added by Developer): it sits behind the set number, with a confirm dialog (WA7, WA7b).
