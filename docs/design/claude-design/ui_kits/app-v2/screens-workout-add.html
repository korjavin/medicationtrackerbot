Workout · add exercise

Adding an exercise mid-workout joins the normal flow (epic med-okwf, brief docs/design/briefs/workout-add-exercise.md). One tap from any exercise screen, no Sets/Reps/Weight form, one pending set pre-filled from last time, and Next › on the last exercise asks "What's next?" with suggestions from your own history. No new components.

Answers to the open questions

Pending Developer's answers.

  • Where's the button? Footer of every exercise screen, and the overview list's last row (.2). The top bar keeps only Finish.
  • Save in the sheet? No: a row tap adds it; a typed name gets an "Add “name”" row.
  • The pre-filled set is a normal pending set with ghost values labelled "last" / "default" / empty.
  • Sheet and Next step share one list: up to 3 suggestions with a reason, then search.
  • Rows, not chips, so each suggestion can say why.
  • Undo toast after adding.
  • Order: the new exercise goes to the end, as today.
