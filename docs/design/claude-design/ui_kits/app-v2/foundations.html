Foundations

The Wandergeek tokens are kept unchanged and renamed to --wg-*. New in v2: five semantic status families, a fixed button hierarchy, control heights, and surface levels for the dark-only shell.

Colour

Sun is reserved for the one primary action in a view and for active navigation. Selection states use raised teal with sun text.

Palette
Surfaces

There are three levels a user can see: the screen, cards and lists, then sheets and dialogs. Floating surfaces (toasts, menus, the rest timer) use --wg-bg-float, which is darker than the cards so they read as layered on top.

Text

fg-3 (60%) is the lowest level allowed for readable text, at about 4.6:1 on cards. fg-4 is only for disabled controls, placeholders and decoration.

Status semantics

Every status family has fg, bg and line tokens. Chips, row states, banners, toasts and dots all read from them. No emoji.

Button hierarchy

Five variants and three sizes replace the roughly 57 button selectors in production. Labels are verbs: "Log" is the verb for measurements and "Add" for things you create.

VariantSpecimenRule
primary
At most one per view. It's the action the screen exists for.
secondary
Alternatives and Cancel. This is the raised teal gloss.
ghost
Tertiary actions, links inside cards, and toolbar text.
danger
The filled variant appears only inside a confirm dialog. The outlined variant is for the entry point.
icon
It always needs an aria-label. The hit area is at least 44px; the sm size is only used inside 56px rows.
disabled
Opacity 0.42, with no gloss shadow.

Heights: --wg-h-sm 36, --wg-h-md 44, --wg-h-lg 52. Radii: xs 6, sm 9, md 12, lg 16, xl 22. Spacing uses an 8pt base (4, 8, 12, 16, 20, 24, 32).

Icons

These are original line icons on a 24px grid with a 1.8 stroke. Use them as <i class="wg-ico" data-icon="pill"></i> and icons.js inlines the sprite reference. Emoji in the app map as: ✅ → check, ⚠️ → alert, 🗑 → trash, ✏️ → edit, 🌍 → globe, and 🏔🚴🚶🏃 → activity with a tag.
