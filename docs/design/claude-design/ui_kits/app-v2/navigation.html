Navigation: 8 slots → 5 tabs

Proposal: Today · Food · Meds · Train · Health. Health holds BP, Weight and Vitals as segments, because all three are "measure, chart, history" screens with the same anatomy. Settings is a gear in every app bar, and Journey opens from the Goal Line and the route icon on Today. The bar drops from two rows to one, which gives about 60px more content on every screen, and the labels stay readable.

Side by side · same content

The same Today content sits above each nav. The current bar uses about 140px including its inset; the proposed one uses 84px, safe area included.

Disabled features: a tab disappears only when its whole feature set is off, and Health hides individual segments. Fewer than 5 tabs is fine; --n on .wg-tabbar sets the columns.

Considered and rejected: the audit's Today / Log / Meds / Progress / Me. "Log" mixes data types and separates capturing a reading from viewing it, so you'd log BP in one tab and read it in another. The global "+" from that option survives as the Log button on Today. A centre FAB was also rejected, because every tab already has a primary in its app bar.
