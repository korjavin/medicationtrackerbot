Components

Every block on the screen pages is built from these classes. Each specimen notes the production pattern it replaces. The specimens are interactive: segmented controls, toggles, picks, choices, set done buttons and the swipe row all respond.

Day navigator

The arrows are fixed 44px cells, and the label truncates instead of pushing them. This fixes the "Yesterday" overlap. Tapping the label opens a date picker. Next is disabled on today.

Rows & lists

Tapping a row opens its editor. Swiping reveals Edit and Delete on touch. The overflow button is the pointer and keyboard path. Long titles wrap to 2 lines.
