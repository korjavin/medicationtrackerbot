Every block on the screen pages is built from these classes. Each specimen notes the production pattern it replaces. The specimens are interactive: segmented controls, toggles, picks, choices, set done buttons and the swipe row all respond.

Trackers

One tile per user tracker on Today. Tapping the body logs the step or toggles the check, and ⋯ opens the log sheet. Tiles never use sun. Met uses ok tokens, and over the limit uses warn tokens only.
