Plans

From Developer (2026-11-04, after the Train timeline): reconsider the Plans tab. Today it is a list of plan names, and a tap opens the editor. This redraws the Plans sub-tab around reading the plan: the current plan with all its days (PL1), a read page per day with Start this day (PL2), and the editor behind Edit (PL3). Brief: docs/design/briefs/plans-tab.md.

Answers to the open questions

First pass, for Developer's approval.

  • Plans opens on the plan, read first. Today a tap on a plan opens the editor with Save in the bar, so reading what's on Thursday means entering edit mode. The plan card (PL1) shows the schedule and every day; a day opens a read page (PL2); Edit plan / Edit lead to the editor (PL3).
  • “Start this day” on the day page. The same “set this day” op as WN7 (med-soo0.1), then start. It answers “I want to do legs today” from the place where you read the legs day.
  • Descriptions move off the rows. They are shown in full on the day page and edited on the Day editor, as today (P2). Rows show the count and last date only.
  • Add plan leaves the app bar. New plan and Import plan are rows at the end; with no plan, “Make a plan” is the empty state's sun (PL5). The app bar keeps only the gear, like the other sub-tabs.
  • “Rotate through days” → “Take days in turn”, and the plan line says “7 days in turn” instead of a Rotating tag.
  • Paused plans (Active off) sit in a Paused list under the current plans, not mixed in with them.
  • Unchanged: the Day and Exercise editor pages (P2, P3), plan storage, sharing, printing, scanning, reminders, the sub-tab id groups.
