BMI on the weight graph

Height is entered once, in Settings → Units & body. Health → Weight then shows BMI and its WHO class next to the current weight, and draws the WHO class borders on the chart wherever they fall inside the current axis. It's hidden entirely in ED-safe mode. Proposed kit additions, in this page's style block: .wg-legend (the chart legend, which today lives only in the web component) and .wg-bmi (the right-aligned read-out).

Answers to the open questions

  • 1 · Lines or shading? Lines (owner's call). Each WHO border is a thin solid hairline at 30% white with the class it starts, written above the line at the right: "Overweight · 25", "Obesity II · 35". Solid and pale, so it can't be mistaken for the dashed sun Goal or the coloured Plan and Actual lines. No fills.
  • 2 · The y-axis. The axis never stretches for a border. A border is drawn only if it already falls inside the data-plus-goal range; there are no off-chart labels. The read-out always names the current class, so nothing is lost.
  • 3 · Colour and words. WHO classes: Underweight · Healthy · Overweight · Obesity I · Obesity II · Obesity III. "Healthy" stands in for WHO's "Normal weight", which reads oddly in a UI. Only Healthy gets the ok chip; every other class uses the neutral chip, with no warn or danger on a body. Warn appears in one place only: a goal below 18.5 (BM3).
  • 4 · Legend. No entry. Each border line carries its own label, so the legend stays Actual / Plan / Goal.
  • 5 · The nudge. Only on the Weight page, as the last row of the chart card, in the spot the BMI read-out would fill. It's a ghost button, so Log keeps the sun. Not on the Today tile: Today is for glancing and doses, and BMI isn't something to fix today.

Also worth deciding

  • Rounding. Choose the class from the rounded one-decimal value, so "24.95" shows as 25.0 · Overweight, never 25.0 · Healthy. The WHO ranges (18.5–24.9) are written for one decimal anyway.
  • Which weight. BMI follows the value in the Now badge (the latest entry). Near a border (BM1 · 24.8) it can flip day to day; a 7-day average would be steadier but would no longer match the badge. Proposed: latest entry, for consistency.
  • Height isn't a history. One value, no dates. Past points are drawn against today's height. That's fine for adults, and it's another reason for the under-18 line.
  • Off switch. Entering a height shouldn't lock BMI on. BM2 has "Show BMI on Weight", which is separate from ED-safe mode.
